# DATA

- Data is a collection of raw facts, figures, observations or values that represent real world entities or event.

# INFORMATION

- Information is a processed, organized and meaningful data that helps users to understand a situation and make decisions.

# DATABASE

- A Database is an organized collection of logically related data that is stored electronically and designed for storage, retrieval and modifications.
- A Database is a structured collection of related data used to store & manage information efficiently.
- Example : Student Data, Banking Application, E-Commerce.

# DATABASE MANAGEMENT SYSTEM

- A Database Management System is a software that allows users to create, store, retrieve, update & manage data in a Database efficiently & securely.
- DBMS is a software that acts as an interface between the user/application & database
- It acts as a bridge between user and the database.

# FILE SYSTEMS

- A file system is a method of storing & organizing data in an individual file where each file contain information related to a specific application or department.
- **COMMON FILE : .csv, .txt, .pptx, .docx, .jpg, .zip etc**

 

## Disadvantages of File System

#### **1. Data Redundancy :**

- The same data stored in multiple files lending to unnecessary duplications.

#### 2. Data Inconsistency :

- Updating data in file but not in others cause inconsistent information.

#### 3. Difficult Data Retrieval :

- Searching & Retrieving data from multiple files is slow and time consuming.

#### 4. Poor Data Sharing :

- Sharing data b/w different applications or user is difficult.

#### 5. No Data Integrity :

- There are no built-in constraints to ensure accuracy & validity of data.

#### 6. No Relationship b/w Files :

- It is difficult to establish and maintain relationships between different files.

#### 7. No concurrent access control :

- Multiple users accessing & modifying the same file simultaneously can lead to conflicts & data corruption.

#### 8. No transaction Management :

- File system do not support transaction so, partial

#### 9. Difficult Back-up & Recovery :

- Back-up & recovery process are manual and less reliable.

#### 10. Poor Scalability :

- As the amount of data grows performance and management becomes difficult.

#### 11. Data Isolation :

- Data is scattered across multiple files in different formats which makes integration difficult.

#### 12. Program Data Dependence :

- Changes in the file structure often require modifications to the applications program.

#### 13. Slow Performance for large Data :

- Searching and updating large files is inefficient.

#### 14. No Query language :

- Users can’t perform flexible search using a standard query language like SQL.

#### 15. Difficult Report Generation :

- Generating reports in file system often required custom programming.

#### 16. Lack of Centralized Control :

- Data is managed separately by difference applications which makes administration difficult.

#### 17. Higher Risk of data loss :

- Accidental deletion or file corruption can result in permanent data loss.

#### 18. Not Suitable for Interprise Applications
